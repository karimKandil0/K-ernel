## Bootloader switch: multiboot2 → Limine
Originally planned multiboot2. Switched to Limine because:
- multiboot2 drops into 32-bit protected mode — would need assembly to enter 64-bit long mode before any Rust runs
- Limine boots directly into 64-bit long mode, Rust entry point runs immediately
- Limine protocol is cleaner: typed request/response structs via `limine` crate
- Multiboot2 note kept in vault, marked superseded, with reason
